ADAPTIVE AI SIGNAL TERMINAL 0.9.44
==================================

QUICK START
1. Use Python 3.11+ 64-bit for source mode.
2. Install: python -m pip install -e ".[full]"
3. Launch: python signal_dashboard.py
4. Headless check: python signal_dashboard.py --once
5. Test suite: python -m pytest -q

USER EXPERIENCE
- The browser opens the read-only local terminal.
- Market cockpit shows closed-candle history, display-only realtime quotes, current decision and available evidence.
- The Top 5 contains only signals that passed strict data, bundle, probability, edge and specialist gates.
- The journal tracks later OHLC-derived WIN/LOSS/TIMEOUT/AMBIGUOUS outcomes and estimated net returns; these are not exchange execution records.

SAFETY CONTRACT
- No order endpoint or exchange-write API is exposed.
- A stale-data, provenance, compatibility, uncertainty or readiness failure remains WAIT.
- Realtime ticker data is display-only; model decisions use the closed-candle path.
- An EXE build may be research-only if no asset passes deployment readiness.
- Never commit API keys or private data; use environment variables.
